# servpro-pwa

SERVPRO PWA rebuild — Motionsites seed wanderful-hero. Independent design study, not affiliated with SERVPRO or The ServiceMaster Company.

Exact marketing strings and green #006341 / #007A3D from the public servpro.com archetype. Cinematic full-viewport hero (storm restoration mood), liquid-glass nav and cards, mouse parallax on the hero plane (paused for reduced-motion, hidden tabs, and offscreen heroes). Chrome-only EN|PT and dark|light. Hero photograph from Unsplash; not a SERVPRO franchise asset.

Installable: manifest.webmanifest, service worker, 192/512 icons.
